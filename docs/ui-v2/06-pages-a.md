- **首屏英雄**：剩余额度大数字（`--fs-display`）是管理员最关心的数；右侧用量放在同一行的 `StatStrip`。剩余额度卡下方 `Meter` = 剩余/总额度，<20% 变 warn，<5% danger。
- 时间范围 `Segmented`（今日/7 天/30 天）影响用量、流量带；沿用旧版 `data-ov-days` 的取值 1/7/30。
- **流量带**替代旧版底部「平台状态」网格：每个平台一条线路，点击线路 → 跳 `/platforms` 并选中该平台。
- 账号状态：5 行 `Meter` 列表，数量为 0 的行文字 `--fg-faint`。底部结论一句：全部正常（ok）或「2 个账号冷却中，查看 →」（跳 `/accounts?status=cooldown`）。
- 告警横幅：旧版若有（批次封控、额度即将耗尽等），在状态行下方显示 `--danger-soft` / `--warn-soft` 横幅，带「查看」按钮。
- 缓存命中：`Ring` + 3 个 KV；底部说明「只统计含缓存字段的上游响应」。
