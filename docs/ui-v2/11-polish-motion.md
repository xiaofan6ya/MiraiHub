# 11 极致打磨：流畅性与细节（v2.2）

> 2026-11-24 21:30。在 10-visual-refresh.md 之上继续，冲突时以本文件为准。目标：**打开即快、切换无闪、操作有回应、细节经得起放大看**。

## 1. 动效系统（替代 01/10 里「禁止入场动画」的条款）
令牌（F1 写进 tokens.css）：
| 令牌 | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 进入、展开 |
| `--ease-in-out` | `cubic-bezier(.65,0,.35,1)` | 位移、切换 |
| `--dur-1` / `--dur-2` / `--dur-3` | 120 / 180 / 260ms | 悬停与按压 / 浮层与 tab / 抽屉与路由 |

允许且要求：
- **路由切换**：内容区 opacity 0→1 + translateY(4px→0)，`--dur-2`；离开不做动画（立即替换），避免两页叠加。浏览器支持 View Transitions 时用它做顶栏标题的平滑替换。
- **按压反馈**：按钮、可点卡片 `:active` 时 `transform: scale(.98)`，`--dur-1`。
- **列表与表格**：首屏骨架 → 数据，用 160ms 淡入，不跳动；排序、筛选后保留滚动位置；新行插入（实时日志）用背景 `--brand-soft` 闪一下 900ms 淡出。
- **数字变化**：KPI 数字更新时用 `font-variant-numeric: tabular-nums` 保持宽度不变，变化的数字淡入 180ms（**不做数字滚动**）。
- **浮层**：下拉、Popover、Tooltip 从触发点方向 4px 位移 + 淡入 `--dur-2`；抽屉 `--dur-3`；弹窗 scale .98→1。
- **线路带**：脉冲速率 ∝ 流量，可见性 hidden 时暂停。
- `prefers-reduced-motion: reduce`：上述全部降为 0ms 或仅淡入。

## 2. 流畅性（性能预算）
- 首屏：路由 chunk 按需加载；**侧栏悬停 / 键盘聚焦到导航项时预取对应页面 chunk**，空闲时（requestIdleCallback）预取同组其余页面。
- 切换已访问页面时不重新出骨架：用 `<KeepAlive :max="6">` 缓存最近页面，回到页面时后台静默刷新（右上角小转圈）。
- 布局零抖动（CLS≈0）：图表、KPI、表格都有固定的最小高度占位；图片和 logo 写 width/height。
- 长列表 >200 行必须虚拟滚动（DataTable 已有能力的要开启）；表格横向滚动时首列和操作列吸附。
- 图表：主题切换时立即重绘（响应式主题），`animationDuration` ≤ 300ms，大数据量关动画；resize 用 ResizeObserver + rAF 节流。
- 轮询：页面不可见时暂停；返回可见时立即刷新一次；同一接口多处使用时合并请求（同 key 去重 300ms）。
- 交互响应：输入筛选 250ms 防抖；按钮点击后立即进入 loading 态，>300ms 才显示转圈，避免一闪。
- 字体：`font-display: swap`，Plex 拉丁子集 preload。

## 3. 细节质感
- **排版**：标题字距 -0.01em；数字一律 tabular-nums；中英文之间留空（文案里补空格）；单位比数字小一级、`--fg-muted`。
- **边框与分隔**：卡片内分隔用 `--border-soft`；hover 行不出现边框跳变；所有 1px 线在高 DPR 下不发虚（不用 0.5px）。
- **焦点**：所有可交互元素都有 `:focus-visible` 环（3px `--ring`），Tab 顺序合理；表格行可键盘上下移动并回车打开详情。
- **空状态 / 错误 / 加载** 三态每页都要有，不允许出现裸「暂无数据」或空白。
- **滚动条**：细滚动条（8px，`--border-strong`，悬停加深），深色下可见。
- **选中文本**：`::selection` 用 `--brand-soft`。
- **图标**：同一行图标与文字基线对齐（`vertical-align: -2px` 或 flex center），尺寸只用 14/16/18/20。
- **深色**：图表网格、骨架、滚动条、禁用态都要单独核对对比度；阴影改为更深的底色 + 1px 高光边（`inset 0 1px 0 rgba(255,255,255,.04)`）。
- **文案**：英文界面不得出现写死的中文；所有时间显示本地时区（Asia/Hong_Kong 用户即 +08:00），悬停显示完整时间。

## 4. 验收清单（每页都过一遍）
1. 首次进入 ≤ 1 个骨架样式，数据到来不跳动。
2. 二次进入无骨架、无闪烁。
3. 主题切换：图表、骨架、滚动条、徽章即时变化。
4. 375 / 1024 / 1440 / 1920 四个宽度无横向溢出（表格容器内部滚动除外）。
5. 只用键盘能完成该页主任务。
6. 英文界面无中文残留。
