## P12 API Keys `/keys`（模板 B）

旧版位置：`#panel-keys`（约 1752–1844 行）+ `key-ip.js`；截图 `keys.png`。

新版把旧版首屏那块巨大的「对外对接信息」**拆开**：Key 列表放首位（最常用），对接信息折叠成一个紧凑卡片 + 「接入指南」抽屉。

```

│ 可用模型 87 组  [DeepSeek-V4.1-Flash 6] [DeepSeek-V4-Pro 5] [GLM-5.3-Flash 5] … [全部 87 ▸] │  ← 只显示前 12 个 chip
└──────────────────────────────────────────────────────────────────────────────┘
搜索名称 [        ]    分组 [全部 ▾]    状态 [全部 ▾]
┌─ DataTable ──────────────────────────────────────────────────────────────────┐
│ 名称 · Key(Copyable mask) · 限额/已用 Meter · 并发 · 来源 IP · 分组 · 到期 · 状态 · 操作 │
└──────────────────────────────────────────────────────────────────────────────┘
```
- ⓘ 鉴权说明里放旧版那段「OpenAI 与 Anthropic 两套协议共用同一批 Key…填错会变成 /v1/v1/messages」原文。
- 「全部 87 ▸」打开模型抽屉：搜索框 + 全部模型 chip（显示「N 平台」，悬停看各平台模型名），点击 chip 复制模型名。
- **接入指南** `DetailDrawer`（640px），页签：OpenAI 协议 / Claude Code·Anthropic / 语音转文字 / AI 生图 / AI 生视频（异步任务）。每页一个 `CodeBlock`（curl），地址与模型名用当前连接地址和第一个可用模型自动填好。内容从旧版 5 个 `<details>` 原样迁移。
- **创建/编辑 Key** `FormDrawer`（640px），按区块分组：基本（名称、分组、备注）· 额度（总额度、每日额度、并发、速率）· 模型（允许的模型/分组）· 访问（来源 IP 绑定，来自 `key-ip.js`）· 有效期。字段与校验以旧版为准。创建成功后弹窗**只显示一次**完整 Key：「请立即复制，关闭后不再显示完整 Key」+ 复制按钮（若旧版 Key 可随时查看明文，则按旧版来，不要擅自改变行为）。
- 行操作：编辑、复制 Key、`⋯`：重置用量、启用/禁用、查看用量（跳 `/logs?key=`）、删除。

## P13 IP 管理 `/ip`（模板 B）

旧版位置：`#panel-ip`（约 1845–1890 行）+ `ip-management.js`、`usage-ip.js`。

```
IP 管理                                                         [封禁 IP]
页签：活跃 IP | 封禁名单 | 设备关联
── 活跃 IP ──
```
