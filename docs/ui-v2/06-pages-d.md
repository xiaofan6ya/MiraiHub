## P22 公开注册入口 `/openentry`（模板 C）

旧版位置：`#panel-openentry`（约 2580–2695 行），关联公开注册页 `/join`（`admin/static/join.html`）与邀请。区块：

## P23 设置 `/settings`（模板 C）

旧版位置：`#panel-settings`（约 2776–2926 行）。区块：
1. **运行配置**：常用 `.env` 项动态修改。每项一行：名称 + 说明 + 控件；需要重启才生效的项旁显示 Badge warn「重启后生效」。顶部说明「exe / apk 部署没有配置文件，改这里即时生效」。保存后若有重启项，显示横幅「有 2 项修改需要重启服务后生效」。
2. **出口代理节点**：DataTable（名称 · 分组 · 地址 · 状态/延迟 · 操作），「添加节点」→ `FormDrawer`。说明「一个出口 IP 上跑几十个号会被上游拉黑。配好出口后，在定时任务里选组名」——「定时任务」做成链接。
3. **WorkBuddy 邀请绑定**：状态 + 表单 + 「停用」。
4. **修改登录密码**：当前密码、新密码、确认新密码（前端校验一致与最小长度，长度规则以后端为准）。成功后提示「密码已修改，其他设备需要重新登录」（若后端会踢出其他会话）。
5. **逆向产物（客户端源码）**：路径 + 「校验并保存」、「设为输出目录」、检索框 +「检索」+ 结果列表。

## P26 登录页

旧版 `admin/static/login.html`（未登录时由后端在 `/admin` 返回）。它是独立静态页、脚本内联、**不经过会话门禁**。
- 新版：同样做成**独立的单文件页面** `admin/ui/login.html`（Vite 多入口），构建为 `dist/login.html`，后端在 S30 切换时改为返回它。
- 布局：页面居中 360px 卡片；上方 MiraiHub 图标 48px + 「MiraiHub 管理后台」；表单字段与旧版完全一致（密码，或其他旧版已有字段）；按钮「登录」；错误信息显示在按钮上方（danger 文字）。背景 `--bg`，卡片无阴影 1px 边框。底部一行 12px `--fg-faint`：版本号。
- 跟随系统深浅色。
