# 功能契约：API 密钥管理页（P6）

**页面标识**: P6（TABS 中的 API 密钥管理）  
**入口函数**: `loadKeys(force, opts={})`  
**路由**: `/keys` 或点击导航栏「API 密钥」

---

## 二、数据来源与接口

### 主接口

#### 列表查询
```http
GET /api/keys?page={page}&page_size={page_size}&search={term}
```

**参数**:
- `page`: 页码（从 1 开始）
- `page_size`: 每页记录数（固定 20）
- `search`: 搜索项（可选，服务端模糊匹配名称）

**返回字段**:

```json
{
  "items": [
    {
      "id": 42,
      "name": "Prod",
      "prefix": "sk_7x9q",
      "status": "active",                       // active | revoked | expired
      "created_at": 1700000000,                 // Unix 时间戳（秒）
      "last_used_at": 1700086000,               // 或 null
      "requests_count": 23200,
      "credit_limit": 1000.0,                   // 额度上限
      "unlimited": false,                       // 是否无限额
      "credit_used": 450.5,                     // 已用额度
      "credit_remaining": 549.5,                // 剩余额度
      "group_id": 0,                            // 0 = 不限制
      "group_name": "生产环境模型",              // 或 null
      "aggregate": true,                        // 是否聚合模型名
      "platform": "",                           // 空 = 不限制
      "platform_label": "WorkBuddy",            // 或 null
      "account_ids": [1, 2, 3],                 // 独占账号列表，[] = 不限制
      "max_concurrent": null,                   // 并发上限，null = 全局
      "rate_per_minute": null,                  // 每分钟请求数，null = 全局
      "note": "生产环境主密钥"
    },
    // ... 更多密钥
  ],
  "total": 42,
  "page": 1,
  "page_size": 20
}
```

#### 创建密钥
```http
POST /api/keys
Content-Type: application/json

{
  "name": "Prod",
  "unlimited": false,
  "credit_limit": 1000.0,
  "group_id": 0,
  "aggregate": true,
  "platform": "",
  "account_ids": [],
  "max_concurrent": null,
  "rate_per_minute": null,
  "note": "生产环境主密钥"
}
```

**返回**:
```json
{
  "id": 42,
  "key": "sk_7x9q8c9d2b3f4e5g6h7i8j9k0",        // 仅返回一次
  ...（其他字段同列表）
}
```

#### 编辑密钥
```http
PATCH /api/keys/{id}
Content-Type: application/json

{
  "name": "Prod-Updated",
  "unlimited": true,
  "credit_limit": null,
  "group_id": 1,
  "aggregate": false,
  "platform": "workbuddy",
  "account_ids": [1, 2],
  "max_concurrent": 10,
  "rate_per_minute": 100,
  "status": "active",                            // 可选，改状态
  "reset_used": true,                            // 可选，重置已用额度
  "note": "备注"
}
```

#### 查看密钥全值
```http
GET /api/keys/{id}/view
```

**返回**:
```json
{
  "id": 42,
  "key": "sk_7x9q8c9d2b3f4e5g6h7i8j9k0",
  "created_at": 1700000000,
  ...
}
```

#### 查看使用统计
```http
GET /api/keys/{id}/usage
```

**返回**:
```json
{
  "id": 42,
  "unlimited": false,
  "credit_limit": 1000.0,
  "credit_used": 450.5,
  "credit_remaining": 549.5,
  "usage_percent": 45,                           // 百分比，0-100
```

```http
DELETE /api/keys/{id}
```

**返回**: 204 No Content

## 三、表格列与操作

### 3.1 列定义

| 列名 | 内容 | 宽度 | 备注 |
|------|------|------|------|
| 名称 | 密钥名 | 180px | 若为空显示「（无名称）」，灰色 |
| 密钥前缀 | 格式 `sk_**xxxx` | 120px | 仅显示前后各 2 字符，中间用 `**` 遮挡 |
| 创建时间 | 相对时间 | 100px | 如「20 天前」「今天」，悬停显示绝对时间 |
| 最后用时 | 相对时间 | 100px | 如「1 分钟前」「从未」（若为 null） |
| 使用次数 | 请求总数 | 80px | 格式化为 `1.2K / 23.2K` 等 |
| 状态 | Badge | 80px | 文本 + 颜色：`active` 绿色「活跃」/ `revoked` 灰色「已禁用」/ `expired` 红色「已过期」 |
| 操作 | 按钮行 | 120px | 见 3.2 |

### 3.2 操作列

#### 「查看」按钮（眼睛图标）
- 点击 → 打开模态框，显示密钥**完整 32 字符值**（仅一次）
- 提供「复制」按钮
- 显示创建时间戳
- 关闭后不再重新查询（若页面刷新则需重新点击）

#### 「更多」按钮（⋯ 菜单）
菜单项：

| 项 | 条件 | 行为 |
|----|------|------|
| 编辑 | 总是 | 打开编辑模态框 |
| 启用 | status = revoked | 切换为 active |
| 禁用 | status = active | 切换为 revoked，Toast「已停用，排队请求将停止，已发往上游的请求继续完成」|
| 查看使用统计 | 总是 | 打开使用统计模态框 |
| 删除 | 总是 | 确认后 DELETE，Toast「已删除」 |

## 四、模态框

### 4.1 创建密钥

**标题**: 「创建 API Key」  
**字段顺序**:

1. **名称**（文本输入，可选）
   - 占位符：「名称（可选）」
   - 验证：1-100 字符

2. **模型分组**（下拉）
   - 选项：「不限制（全部可用模型）」+ 分组列表
   - 默认：「不限制」
   - 说明文本：「不限制 = 可用全部启用模型；选了分组则只能调用组内模型。」

3. **聚合模型**（复选框，默认勾选）
   - 文本：「开启后模型列表按「同模型跨平台」合并，调用聚合名可由网关挑平台转发。」

4. **独占平台**（下拉，可选）
   - 选项：「不限制（全部平台）」+ 平台列表
   - 默认：「不限制」
   - 说明文本：「绑定后该 Key 只在这个平台的账号池里选号；请求头 X-Platform 仍可覆盖。」

5. **独占绑定账号**（多选面板，可选）
   - 触发器文本：「不限制（使用公共账号池）」或「已选 N 个账号 · 只用这些，不换号」
   - 面板内容：
     - 搜索框（服务端防抖 250ms）
     - 账号列表，每行：复选框 + 账号名 + UID + 平台 + 余额 + 状态
     - 脚注：「已加载 50 / 共 N 个」（仅首页不分页拉取）
     - 已选的账号 ID 存在隐藏 input 中，翻页/搜索不会丢
   - 说明文本：「独占后公共池跳过这些账号；此 Key 仅用这些账号的积分和权益，账号不可用时不会换。」

6. **限额设置**
   - 单选卡片或复选框：「不限额（∞，默认）」（勾选后下方金额输入禁用）
   - 金额输入：数字，可选
   - 说明文本：「取消后可填写积分上限；0 表示零额度。」

7. **并发上限**（数字输入，可选）
   - 占位符：「并发上限（空=全局，0=不限）」
   - 说明文本：「空=全局默认；0=不限；N=此 Key 所有对话合计最多 N 个在途请求。」

8. **每分钟请求数**（数字输入，可选）
   - 占位符：「每分钟请求数（空=全局，0=不限）」
   - 说明文本：「频率与并发独立。提高并发不会提高每分钟请求额度。」

9. **备注**（文本输入，可选）
   - 占位符：「备注（可选）」
   - 验证：0-500 字符

**按钮**:
- [取消] [创建]

**成功后**:
- 显示成功模态框，显示生成的密钥全值（仅一次）
- 提供「复制」按钮
- 点击「完成」→ 刷新列表，关闭模态框

### 4.2 编辑密钥

**标题**: 「编辑 API Key」  
**字段**（与创建相同，但预填当前值）：

1. **名称**
   - 验证：**必填**，1-100 字符

2. **模型分组**（同创建）

3. **聚合模型**（同创建）

4. **独占平台**（同创建）

5. **独占绑定账号**（同创建）

6. **积分限额**
   - 若 `unlimited=true`，显示「∞」
   - 若 `unlimited=false`，显示具体数字
   - 单选卡片：「不限额（∞）」

7. **重置已用额度**（复选框）
   - 文本：「当前已用 X，勾选后归零（不影响历史日志）。」

8. **并发上限**（同创建，预填或空）

9. **每分钟请求数**（同创建，预填或空）

10. **备注**（同创建）

**按钮**:
- [取消] [保存]

**保存后**:
- Toast「已保存」
- 自动刷新列表

### 4.3 查看密钥全值

**标题**: 「查看 Key — {密钥名}」  
**内容**:
- 创建时间戳（文本）：「创建于 2024-11-20 14:30:45」
- 密钥值（只读文本输入，等宽字体）
- 「复制」按钮

**行为**:
- 打开时调用 `GET /api/keys/{id}/view`
- 显示加载状态
- 失败时显示错误提示

### 4.4 使用统计

**标题**: 「Key 用量 — {密钥名}」  
**内容**:

```
┌────────────────┬────────────────┬────────────────┬────────────────┐
│ 限额           │ 已用           │ 剩余           │ 使用率         │
│ 1,000.00       │ 450.50         │ 549.50         │ 45%            │
└────────────────┴────────────────┴────────────────┴────────────────┘
```

- 四个数值卡片
- 若 `unlimited=true`，限额显示「∞（无限制）」，剩余显示「∞」，使用率显示「—」
- 若 `unlimited=false`，显示进度条（高度 12px，宽 100%）：
  - 着色规则：
    - `usage_percent >= 90%` → 红色（danger）
    - `usage_percent >= 60%` → 琥珀色（warn）
    - `usage_percent < 60%` → 绿色（ok）

**底部状态行**:
- 状态：「正常」（绿色）/ 「已停用」（红色）
- 创建时间戳

## 五、交互与行为

### 5.1 页面加载

**首次进入**:
1. 显示加载状态
2. 调用 `GET /api/keys?page=1&page_size=20`
3. 渲染表格
4. 表格默认按创建时间**倒序**排列（新建的在最上面）

**搜索**:
1. 本地过滤（前 500ms 内不调用后端）
2. 若输入字符数 ≥ 2，防抖 250ms 后调用 `GET /api/keys?search={term}&page=1&page_size=20`
3. 清空搜索框 → 显示全部

**分页**:
- 点击页码 → 调用 `GET /api/keys?page={page}&page_size=20`
- URL 保持同步（可选）

### 5.2 创建密钥

**流程**:
1. 点击「创建新密钥」→ 打开模态框
2. 表单预加载：
   - 调用 `GET /api/groups`
   - 调用 `GET /api/platforms`
   - 调用 `GET /api/accounts?all_platforms=1&page_size=50&page=1`
3. 用户填写表单
4. 点击「创建」→ POST `/api/keys` → 显示成功模态框
5. 点击「完成」→ 刷新列表

**表单约束**:
- 若平台已选，账号选择器只显示该平台的账号
- 若未选平台，显示全部平台的账号

### 5.3 编辑密钥

**流程**:
1. 表格行 → 展开右侧详情面板，或点击「更多」→「编辑」
2. 打开编辑模态框，预填当前值
3. 修改后点击「保存」→ PATCH `/api/keys/{id}` → 自动关闭模态框，刷新列表

**编辑限制**:
- 名称必填
- 若勾选「重置已用额度」，`reset_used: true` 一起发送

### 5.4 切换密钥状态

**从菜单项**:
1. 「禁用」→ 确认对话 → PATCH `/api/keys/{id}` with `status: revoked` → Toast
2. 「启用」→ 无确认 → PATCH `/api/keys/{id}` with `status: active` → Toast

**行为**:
- 禁用后该 Key 不再接受新请求，但已发往上游的请求继续完成
- 启用后恢复正常

### 5.5 删除密钥

**流程**:
1. 表格「更多」→「删除」
2. 确认对话：「确认删除该 Key？此操作不可恢复。如需临时停止调用，请使用停用按钮。」
3. 点击「确认」→ DELETE `/api/keys/{id}` → Toast「已删除」→ 刷新列表

## 七、数据展示规范

### 7.1 时间格式

**相对时间**（表格「创建时间」「最后用时」列）:
- 规则：
  - 今天 → 「今天」
  - 昨天 → 「昨天」
  - 7 天内 → 「N 天前」
  - 大于 7 天 → 「N 个月前」
  - 超过 1 年 → 「N 年前」
  - 从未使用 → 「—」或「从未」

**绝对时间**（模态框、详情面板）:
- 格式：`YYYY-MM-DD HH:mm:ss`（本地时区，UTC+8）
- 例：`2024-11-20 14:30:45`

### 7.2 数字格式

**使用次数**（表格列）:
- ≥ 1000 → `1.2K` / `23.2K`
- < 1000 → `123`
- 规则：千进制，1 位小数

**额度数字**（详情面板、模态框）:
- 格式：千分位 + 2 位小数
- 例：`1,234.56`
- 若为 ∞ → 显示「∞」

**使用率**（使用统计）:
- 格式：百分比 `0%-100%`
- 若无限额 → 显示「—」

### 7.3 着色与 Badge

**状态 Badge**:
- `active` / 「活跃」/ 绿色（`--c-ok`）
- `revoked` / 「已禁用」/ 灰色（`--fg-faint`）
- `expired` / 「已过期」/ 红色（`--c-danger`）

**使用率进度条**:
- ≥ 90% → 红色（`--c-danger`）
- ≥ 60% → 琥珀色（`--c-warn`）
- < 60% → 绿色（`--c-ok`）

## 八、边界情况与容错

### 8.1 数据缺失

| 情况 | 显示 |
|------|------|
| 密钥名为空 | 「（无名称）」，灰色 `--fg-faint` |
| 最后使用时间为 null | 「—」或「从未」 |
| 使用次数为 0 | 「0」 |
| 账号绑定为空数组 | 「不限制」或「使用公共账号池」 |
| 平台为空字符串 | 「不限制（全部平台）」 |
| 模型分组为 0 | 「不限制（全部可用模型）」 |

### 8.2 加载态与错误

**列表加载中**:
- 显示 5 行骨架屏（灰色占位符）
- 或显示「加载中…」文本

**模态框加载中**:
- 显示「加载中…」文本

**请求失败**:
- Toast 显示错误信息：「创建失败：{detail}」/ 「保存失败：{detail}」
- 若列表加载失败，显示「加载失败」提示 + 「重试」按钮

**响应超时**（> 10 秒）:
- 显示降级提示（若有缓存则显示上次数据）
- 后台继续重试

### 8.3 权限与禁用状态

| 情况 | 表现 |
|------|------|
| 密钥已过期（status=expired） | 表格 Badge 显示「已过期」（红色），菜单项禁用（除删除外） |
| 密钥已禁用（status=revoked） | 表格 Badge 显示「已禁用」（灰色），行整体 60% 不透明 |
| 操作无权限 | Toast 显示「无权限进行此操作」 |

## 十一、实现要点

1. **缓存策略**：列表数据缓存 30 秒，用户点击刷新或搜索时绕过缓存
2. **性能优化**：
   - 表格虚拟化（若行数 > 100）
   - 详情面板延迟渲染（点击时才加载）
   - 账号选择器首页不超 50 条
3. **搜索**：
   - 本地过滤（字符数 < 2）
   - 服务端搜索（防抖 250ms，字符数 ≥ 2）
   - 搜索结果重置到第 1 页
4. **表单验证**：
   - 名称：1-100 字符（创建可空，编辑必填）
   - 金额：≥ 0，可空
   - 并发/频率：≥ 0，可空
5. **无障碍**：
   - 表格用 `<table>` 语义标签
   - 操作按钮用 `<button>` 且有 `aria-label`
   - 密钥值用 `aria-label` 提供完整文字（避免逐字读出 32 字符）
6. **国际化**：所有文案（「创建」「编辑」等）提取到 i18n
7. **主题适应**：所有颜色使用 CSS Custom Properties（`--c-ok / --c-warn / --c-danger / --fg-faint`）

## 十二、API 时序流程

```
[ 创建 Key 流程 ]
1. openAddKey() 
   → GET /api/groups      ✓
   → GET /api/platforms   ✓
   → GET /api/accounts... ✓
   → 显示模态框

2. submitAddKey()
   → POST /api/keys       ✓
   → 显示成功（密钥全值）
   → 点「完成」

3. closeModal()
   → loadKeys()
   → GET /api/keys?page=1 ✓
   → 刷新表格

[ 编辑 Key 流程 ]
1. editKey(id)
   → GET /api/groups      ✓
   → GET /api/platforms   ✓
   → GET /api/accounts... ✓
   → 显示模态框

2. submitEditKey(id)
   → PATCH /api/keys/{id} ✓
   → Toast「已保存」

3. loadKeys()
   → GET /api/keys?page=1 ✓
   → 刷新表格

[ 查看密钥流程 ]
1. viewKeyFull(id, name)
   → 显示模态框（加载中…）
   → GET /api/keys/{id}/view ✓
   → 显示密钥全值

[ 查看使用统计流程 ]
1. viewKeyUsage(id, name)
   → 显示模态框（加载中…）
   → GET /api/keys/{id}/usage ✓
   → 显示进度条 + 数字

[ 切换状态流程 ]
1. toggleKeyStatus(id, button)
   → PATCH /api/keys/{id} with status ✓
   → Toast「已启用」或「已禁用」
   → loadKeys()
   → GET /api/keys?page=1 ✓

[ 删除 Key 流程 ]
1. deleteKey(id)
   → 确认对话
   → DELETE /api/keys/{id} ✓
   → Toast「已删除」
   → loadKeys()
   → GET /api/keys?page=1 ✓
```
