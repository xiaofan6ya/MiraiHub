# 功能契约：数据看板页（Dashboard）

**页面标识**: P11（TABS 第十一个）  
**入口函数**: `loadDashboard(days, granularity, platform, model)`  
**路由**: 点击导航栏「数据看板」或直接访问

---

## 一、页面整体结构

```
┌─ 时间窗口切换 + 粒度选择（1/7/30天 × 小时/天）
├─ 平台/模型过滤栏
│
├─ 上半屏：KPI 一排 7 张卡
│  ├─ 总数 / 总积分 / 总Token / 缓存读取 / RPM / TPM / 成功率

│
├─ 中上屏：性能健康条
│  ├─ 成功率、平均延迟、吞吐TPS、首字TTFB（4格横行）
│  └─ 下方显示 TOP 8 模型芯片（成功率着色）
│
├─ 中屏：消耗分布（可切换视图）
│  ├─ 视图选择：堆叠柱状 / 堆叠面积 / 单线趋势

├─ 下屏：模型调用分析（三个视图切换）
│  ├─ 视图 1 - 趋势：多条线，每条代表一个模型的请求数趋势

├─ 右下辅助卡片
│  ├─ 平台贡献（按平台分摊的请求数 + 成功率）

│
└─ 底部：数据更新时间 + 刷新按钮
```

## 二、数据来源与接口

### 主接口

```http
GET /api/stats/dashboard?days={1|7|30}&granularity={hour|day}&platform=&model=&top_models={1..12}
```

**参数**:
- `days`: 时间窗口（1、7、30 天）
- `granularity`: 粒度（hour 或 day），超过 7 天自动降级为 day
- `platform`: 平台过滤（空=所有平台）
- `model`: 模型过滤（空=所有模型）
- `top_models`: 返回前 N 个模型（默认 6，范围 1-12）

## 三、数据展示规范

### 3.1 数字格式化

#### 缩写格式（`cnum()`）
- ≥ 1 亿（1e8）：显示为 B（亿），2 位小数，如 `1.23B`
- ≥ 1 万（1e4）：显示为 M（万），2 位小数，如 `12.34M`  
- ≥ 1 千（1e3）：显示为 K（千），1 位小数，如 `1.2K`
- < 1 千：显示原数，四舍五入

#### 千分位格式（`exact()`）
- 用于精确计数，千分位分组，如 `1,234,567`

#### 金额格式（`credit()`）
- 千分位 + 固定 2 位小数，如 `1,234.56`

#### 百分比格式（`pct()`）
- 乘以 100，固定 2 位小数，如 `98.40%`

#### 时间格式（`latency()`）
- < 1 秒：毫秒，如 `450 ms`
- 1-60 秒：浮点秒，如 `1.23 秒`
- > 60 秒：分秒，如 `1 分 23 秒`

#### 时间桶标签（`bucketLabel()`）
- 小时粒度：`HH:mm`，如 `15:30`
- 日粒度：`MM/DD`，如 `11/23`

### 3.2 着色规则

#### 成功率着色
- 绿色（`ok`）：≥ 98%
- 黄色（`warn`）：90% ≤ < 98%
- 红色（`danger`）：< 90%

#### 模型芯片着色
- 根据该模型的成功率三档着色
- 深蓝背景 + 彩色圆点指示

## 四、交互与行为

### 4.1 页面加载

**首次进入**:
1. 显示加载骨架屏
2. 调用 `GET /api/stats/dashboard?days=1&granularity=hour&platform=&model=`
3. 渲染 KPI 卡、图表、表格

**时间窗口切换** (1天 ↔ 7天 ↔ 30天):
1. 更新 `days` 参数
2. 粒度自动调整：days > 7 时降级为 `day`
3. 重新调用接口，动画更新图表

**粒度切换** (小时 ↔ 天):
1. 仅在 7 天内允许
2. 更新 `granularity` 参数，重新调用

**平台/模型过滤**:
1. 更新对应参数，调用接口
2. 其他筛选组件保持状态

### 4.2 操作

#### 时间窗口按钮
- 位置：页面顶部
- 显示：当前选中的天数（1/7/30）
- 点击切换窗口

#### 粒度选择（仅 ≤7 天）
- 位置：时间窗口按钮旁
- 选项：小时、天
- 禁用提示：「超过 7 天仅支持日粒度」

#### 图表视图切换（消耗分布）
- 位置：消耗分布卡片顶部
- 选项：柱状 / 面积
- 记住用户选择

#### 分析模式切换（模型调用分析）
- 位置：模型分析卡片顶部
- 选项：趋势 / 分布 / 排行
- 切换时平滑过渡

#### 刷新按钮
- 位置：页面顶部右侧
- 行为：`loadDashboard(force=true)`
- 显示最后刷新时间

## 五、SVG 图表规范

### 5.1 堆叠柱状/面积图

**参数**:
- `buckets`: 时间桶数组
- `series`: 数据序列（每个模型一条）
- `mode`: `bar` 或 `area`
- `unit`: `credits` 或 `tokens`

**绘制规则**:
- X 轴：时间（底部）
- Y 轴：金额或 tokens（左侧）
- 堆叠：从底往上累加
- 颜色：调色板循环（8 色）
- 动画：从下往上填充（延迟 12ms/根）

**交互**:
- 悬停显示 tooltip：`模型名 · 数值 · 时间桶`
- 移出隐藏 tooltip

### 5.2 多线趋势图

**绘制规则**:
- 每个模型一条线
- 线上打点（圆点表示数据点）
- 线条笔画宽度 1.8px
- 颜色同堆叠图

**交互**:
- 悬停点显示 tooltip
- 鼠标移出隐藏

### 5.3 排行条形图

**绘制规则**:
- 横向条形，从左往右
- 宽度按占比缩放
- 旁显示排名、模型名、占比百分比

## 六、跨页联动

### 6.1 平台上下文
- 所有数据自动按 `X-Platform` 请求头过滤
- 切平台时自动刷新看板数据

### 6.2 导航跳转
- 点击某模型行 → 跳转到「模型广场」（P10）并高亮该模型
- 点击某平台贡献行 → 跳转到「平台管理」（P4）

## 七、边界情况与容错

### 7.1 数据缺失或异常

| 情况 | 处理 |
|------|------|
| 窗口内无请求 | 卡片显示 `0`，图表显示「暂无数据」 |
| 模型/平台为空 | 显示「暂无数据」或默认显示所有 |
| 计算异常（分母为 0） | 显示 `—` 或 `0.00` |
| 缺少 TOP 模型信息 | 只显示有数据的模型 |

### 7.2 加载态与错误

**加载中**:
- 显示骨架屏（KPI 灰色占位、图表灰色背景）
- 禁用时间窗口切换

**请求失败**:
- 显示 Toast：「数据加载失败，请重试」
- 保留上次成功的数据
- 提供「重试」按钮

**响应超时**（> 10 秒）:
- 显示降级视图（上次缓存）
- 后台继续重试

### 7.3 空状态

| 场景 | 显示 |
|------|------|
| 账户被禁用 | 顶部横幅「账户已禁用」，内容置灰 |
| 无平台可用 | 「没有可用平台」 |
| 新账户（无使用记录） | 「暂无数据，请先调用 API」 |
| 过滤条件无匹配 | 「没有符合条件的数据」 |

## 八、实现要点

1. **缓存策略**：看板数据缓存 1-2 分钟，时间窗口切换时绕过缓存
2. **性能优化**：
   - SVG 图表一次性生成（而非逐帧 append）
   - 视图切换时整块替换 SVG
   - 避免重排，使用 CSS transform 动画
3. **无障碍**：
   - 卡片用 `<article>` 标签，标题用 `<h3>`
   - 图表用 `role="img"` 和 `aria-label`
   - 数字用 `<span aria-label="完整数字">` 提供完整文字
4. **国际化**：所有文案（「总数」「成功率」等）需提取到 i18n 配置
5. **主题适应**：所有颜色变量用 CSS Custom Properties
6. **调色板**：8 色循环，支持亮/暗主题
