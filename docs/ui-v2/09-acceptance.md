# 09 验收清单与上线切换

## 1. 每步通用验收（审核执行模型的交付时逐条核对）

- [ ] `npm run typecheck`、`npm run test`、`npm run build` 三条全部通过，输出已贴出。
- [ ] 没有修改 `admin/console/`、`admin/static/`；除 S02、S30 外没有修改 Python 文件。
- [ ] `git diff` 中页面/组件文件里没有裸十六进制颜色：`grep -rnE "#[0-9a-fA-F]{3,8}\b" admin/ui/src --include=*.vue` 只允许出现在 tokens.css 和注释里。
- [ ] 页面里没有直接 `fetch(`：`grep -rn "fetch(" admin/ui/src/pages` 结果为空。
- [ ] 没有新增 README 允许清单以外的依赖（看 package.json diff）。
- [ ] 该页 `contracts/<page>.md` 存在，「实现对照」表里没有「未实现」。
- [ ] 浅/深色、1440/1024/375 三个宽度截图无溢出、无文字被截断、无横向滚动条（表格容器内部除外）。

## 2. 视觉一致性抽查（S21 概览完成后做一次，S30 前再做一次）

- [ ] 一屏内品牌靛色面积很小，只出现在主按钮、选中导航、链接、焦点。
- [ ] 状态颜色映射全站一致（同一个「冷却」在账号池、概览、积分到期里是同一个琥珀色 Badge）。
- [ ] 卡片没有阴影、没有嵌套卡片；只有浮层有阴影。
- [ ] 统计数字都是等宽数字，数值列右对齐。
- [ ] 表头没有全大写、没有字间距。
- [ ] 线路带只出现在概览、平台网关、风控哨兵三处。
- [ ] 没有入场动画、悬停上浮、点击波纹。
- [ ] 每个页面只有一个主按钮。
- [ ] 长说明已收进 HelpTip，页面主视线干净。

## 3. 功能对齐（S30 前，人工对着旧版逐页过）

按页面逐个打开旧版 `/admin?tab=<key>` 和新版 `/admin/v2/#/<key>`：
- [ ] 同一时间范围下，统计数字一致（剩余额度、请求数、Token、成功率、积分）。
- [ ] 每个按钮在新版都能找到，并且行为相同（以 contracts 为准）。
- [ ] 切换平台后，依赖平台的页面都刷新。
- [ ] 危险操作都有确认框，文案是问句 + 后果。
- [ ] 后台批量任务有进度、能看到失败项。
- [ ] 手机宽度（375px）下每页可用，表格是卡片。
- [ ] 桌面版（EXE）里新版能打开，更新检查可用，窗口可拖动。
- [ ] 安卓版里新版能打开（若 APK 打包流程本次已接入）。
- [ ] 断网（拔网线）情况下页面样式、图标、字体完整。

## 4. 上线切换步骤（给维护者）

1. S30 合并后，默认仍是旧版（`MIRAIHUB_CONSOLE=v1`）。新版可通过 `/admin/v2/` 访问试用。
2. 试用期：日常操作改用新版，发现问题记录到 issue，修复后重新 `npm run build` 并提交 dist。
3. 正式切换：设置 `MIRAIHUB_CONSOLE=v2` 并重启。登录后自动进入新版；侧栏底部「切回旧版」可临时回退。
4. 保留旧版一个发布周期。确认无回退需求后，另开任务删除 `admin/console/`（以及 S30 加的切换开关），这一步不在本方案范围内。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 低成本模型漏掉旧版功能 | 每页先写 contracts，再实现，再写「实现对照」表；审核时只看对照表和 diff |
| 平台差异多（每个平台账号操作不同），账号池写偏 | 账号池拆成 S25/S26 两步；平台特有逻辑集中在 `src/platforms/`；无法验证的平台在交付说明中列出，由维护者实测 |
| dist 忘记重建导致线上是旧代码 | BUILD.md 写明；可选：S30 的 smoke 脚本对比 `dist/index.html` 修改时间与 `src` 最新修改时间，落后时告警 |
| CSP 拦截新资源 | S02 专门检查并补测试 |
| 同一设置两处修改不同步（选号策略） | S23 确认后共用 store |
