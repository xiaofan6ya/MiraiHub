## P6 账号池 `/accounts`（模板 B，全站最复杂的页面）

旧版位置：`#panel-accounts`（约 1625–1751 行），逻辑散在 `console-app.js`（账号相关函数）、`platform-actions.js`、`profile-transfer.js`，平台特有接口在 `admin/platform/**/routers/`。

> 执行前必做：把旧版本页所有功能抽进 `contracts/accounts.md`，特别是**每个平台各有哪些列和操作**（WorkBuddy / Trae / Qoder / Loomy / Marvis / 等），以及后台批量任务的轮询机制。新版靠「后端能力声明」驱动列和操作，拿不准的按旧版行为 1:1 复刻。

### 页头操作
- **主操作「添加账号 ▾」**：下拉，列出当前平台支持的添加方式（来自平台能力声明）：手机号登录 / 浏览器授权登录（PKCE）/ 手动添加 / 导入。不支持的方式不出现。
- 次要操作：导入、扫描本机（桌面端才有，调用 `WBDesktop`/后端扫描接口 → 预览可导入的客户端账号）、导出（导出当前筛选结果，格式以旧版为准）。
- 各添加方式：
  - **手机号登录** `FormDrawer`：区号选择 + 手机号 + 获取验证码（倒计时按钮）+ 验证码；成功后账号入池。复用旧版 `phone-session.js` 的区号与流程逻辑。
  - **浏览器授权（PKCE）**：按旧版流程（打开授权 URL → 轮询/回调 → 入池），用步骤条展示状态。
  - **手动添加** `FormDrawer`：字段由平台决定（token / cookie / 账号密码等），从旧版手动添加表单移植。
  - **导入** `FormDrawer`：拖放或粘贴，解析后用小表格预览（账号 + 校验结果），勾选后导入。

### 状态页签与筛选
- 页签：全部 / 已启用 / 已禁用 / 冷却 / 熔断（+ 计数），对应 `?status=`。搜索按账号名与备注。
- 冷却/熔断/额度耗尽的账号，状态 Badge 用对应色，并在状态上悬停显示原因与恢复时间。

### 表格列（通用列 + 平台扩展列）
通用：复选框、账号（名称/脱敏号 + 平台特有副标题）、状态 Badge、剩余额度（`Meter` + `剩余/总`）、今日消耗、到期（`fmtExpiry`）、最近使用（`fmtRelative`）、备注（可内联编辑）、操作。
平台扩展列：由能力声明追加（如某平台有「等级」「设备指纹」列）。列显示设置可让用户隐藏列。

### 行操作
直接显示：刷新额度、检测。`⋯` 菜单：启用/禁用、编辑备注、查看详情（`DetailDrawer`：账号全部字段、额度明细、最近请求、冷却/封控历史）、平台特有操作、绑定/解绑、删除（danger，确认框）。

### 批量工具条
启用 / 禁用 / 刷新额度 / 检测 / 导出选中 / 删除（danger）。
整体批量（不依赖选中）：刷新全部、模型额度与冷却、成长任务与领奖、猫猫旅行与领奖 —— 这些是**后台任务**：点击 → 确认 → 启动 → 顶部出现内联 `JobProgress` 条 + 右下 `JobProgress` 卡片，轮询进度（机制复刻旧版 `accountJobStatus`）。任务完成 Toast「已刷新 3 个账号额度 · 1 失败」，失败项可展开查看。
平台特有的整体操作（成长任务、猫猫旅行）只在支持的平台显示。

## P9 成长计划 `/growth`（模板 A/B 混合）

旧版位置：`#panel-growth`（`#growthCenter` 容器），逻辑 `growth_center.js`、样式 `growth_center.css`。

> 这页旧版是独立渲染的「成长中心」。执行前必须把 `growth_center.js` 的结构抽进 `contracts/growth.md`：它展示每个账号的成长任务、领奖状态、进度、可执行的动作（做任务/领奖）。

```
成长计划 · <平台>                                      [全部领奖] [刷新]
StatStrip：可领奖励 | 进行中任务 | 今日已领 | ...（按 growth_center 实际字段）

│ 每个账号一张卡/一行：账号 · 等级/进度 Meter · 任务清单(状态) · [做任务][领奖]  │
└────────────────────────────────────────────────────────────────────────────┘
```
- 保留 `growth_center.js` 的全部动作与字段，只换外观（卡片/进度/徽章用新组件）。任务执行与领奖是后台任务 → `JobProgress`。
- 只对声明支持成长体系的平台显示有意义内容；不支持的平台显示 `Empty`「当前平台没有成长计划」。
