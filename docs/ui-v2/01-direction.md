# 01 设计方向

## 1. 产品是什么、给谁用、主要任务

- **是什么**：一个把多家上游平台（WorkBuddy、Trae、Qoder、Loomy、WPS 灵犀、Marvis……）聚合成标准 OpenAI / Anthropic 协议的网关的管理后台。
- **谁用**：网关管理员（通常是一个人或一个小团队），每天打开几次，桌面端为主，偶尔手机查看。
- **主要任务（按频率）**：
  1. 看一眼：服务是否正常、额度还剩多少、哪个平台在报错。
  2. 管账号：添加、导入、刷新额度、禁用坏号。
  3. 管调用方：发 Key、看用量、查日志、封 IP。
  4. 调策略：平台调度顺序、选号策略、模型白名单。
  5. 偶尔：客户端参数、告警渠道、系统设置、升级。

## 2. 设计概念：「调度台」

网关的本质是**把一路请求分流到多条上游线路**。整套界面围绕这个意象：

- **唯一的视觉记忆点 = 「线路带」(Route Ribbon)**：一条横向的分流图，左边是调用方，右边是各平台线路，
  每条线路的**粗细 = 流量占比**、**颜色 = 健康度**、末端显示请求数与成功率。它出现在概览首屏、平台网关、风控哨兵三处，
  替代旧版的「节点 + 虚线 + 粒子」图。其余所有界面保持安静、克制。
- 其余界面：白纸 + 墨色文字 + 一种靛蓝品牌色。颜色只用来表达状态，不做装饰。
- 不做渐变背景、不做玻璃拟态、不给每张卡片加阴影、不做入场动画。

## 3. 色彩

色值以 [tokens.css](tokens.css) 为准。命名取自传统色，便于口头沟通。

### 浅色（默认）

| 名称 | 角色 | 值 |
|---|---|---|
| 霜白 | 页面底色 `--bg` | `#F3F5F8` |
| 纸 | 卡片/表格底 `--surface` | `#FFFFFF` |
| 墨 | 主文字 `--fg` | `#171A21` |
| 靛 | 品牌/主操作/选中 `--brand` | `#3148C8` |
| 青瓷 | 成功/健康 `--ok` | `#14866A` |
| 琥珀 | 警告/冷却/快到期 `--warn` | `#B7791F` |
| 朱 | 错误/封禁/危险操作 `--danger` | `#C8382B` |

### 深色

| 名称 | 角色 | 值 |
|---|---|---|
| 夜 | `--bg` | `#12151B` |
| 石板 | `--surface` | `#1A1E26` |
| 月白 | `--fg` | `#E6E9EF` |
| 靛（提亮） | `--brand` | `#7D8FFF` |
| 青瓷 | `--ok` | `#3CC497` |
| 琥珀 | `--warn` | `#E0A743` |
| 朱 | `--danger` | `#F0675A` |

### 用色规则

1. **品牌色只用于**：主按钮、选中的导航项、选中的分段控件、链接、焦点环、线路带里「当前首选平台」。一屏里品牌色面积不超过 5%。
2. **状态色只用于状态**：徽章、数字着色、线路带颜色、进度条。不要拿状态色当装饰。
3. 状态与颜色的固定映射（全站一致）：
   - 活跃 / 成功 / 正常 / 已启用 → `ok`
   - 冷却 / 限流 / 快到期（≤7 天）/ 部分失败 → `warn`
   - 熔断 / 封禁 / 失败 / 额度耗尽 / 已过期 → `danger`
   - 已禁用 / 未知 / 无数据 → `fg-muted`（灰）
   - 进行中 / 信息 → `brand`
4. 每种状态色都有 `-soft` 版本（10–14% 透明度底色）用于徽章底和行高亮。
5. 文字对比度 ≥ 4.5:1；`--fg-muted` 只用于次要说明，不用于可点击文字。

## 4. 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| 西文与数字 | **IBM Plex Sans**（400/500/600，通过 `@fontsource/ibm-plex-sans` 本地打包，只打 latin 子集） | 带工程感的无衬线，等宽数字清晰，契合「网关/调度」 |
| 中文 | 系统字体栈：`"PingFang SC","HarmonyOS Sans SC","MiSans","Microsoft YaHei UI","Microsoft YaHei","Noto Sans CJK SC",sans-serif` | 不打包中文字体（体积过大） |
| 代码/Key/URL/模型 ID | **JetBrains Mono**（400/500，`@fontsource/jetbrains-mono` 本地打包） | 只用于真正的代码类字符串，不用于普通数字或标签 |

完整字体栈：`--font-sans: "IBM Plex Sans", <中文栈>;` 数字一律 `font-variant-numeric: tabular-nums`。

### 字号阶梯（px / 行高）

| 令牌 | 用途 | 字号 | 行高 | 字重 |
|---|---|---|---|---|
| `--fs-display` | 概览首屏的大数字（剩余额度） | 40 | 44 | 600 |
| `--fs-h1` | 页面标题 | 22 | 30 | 600 |
| `--fs-h2` | 卡片/区块标题 | 15 | 22 | 600 |
| `--fs-stat` | 统计卡数字 | 26 | 32 | 600 |
| `--fs-body` | 正文、表格内容、表单 | 14 | 22 | 400 |
| `--fs-small` | 次要说明、表头、徽章 | 12 | 18 | 400/500 |
| `--fs-tiny` | 图表坐标轴、角标 | 11 | 16 | 400 |

规则：
- 表头用 12px / 500 / `--fg-muted`，**不用全大写、不加字间距**。
- 不在标题里给单个词换颜色或加粗。
- 中文段落行长不超过 40 个汉字（约 640px），说明文字放在 `max-width: 68ch` 的容器里。

## 5. 间距、圆角、阴影

- 间距基于 4px：`4 8 12 16 20 24 32 40 48`。卡片内边距 20px，卡片之间 16px，页面左右边距 32px（≤1280px 时 24px，手机 16px）。
- 圆角**按层级区分**，不是全站一个值：
  - 页面级容器（卡片、表格外框、抽屉）：`10px`
  - 控件（按钮、输入框、下拉、分段控件）：`7px`
  - 徽章、标签 chip：`5px`
  - 状态圆点、头像：`50%`
- 阴影：卡片**不用阴影**，只用 1px 边框 `--border`。只有浮层（下拉菜单、弹窗、抽屉、Toast、命令面板）用 `--shadow-pop`。
- 分隔：同一卡片内的分组用 1px `--border-soft` 横线，不用嵌套卡片（旧版「卡片里套卡片」是视觉噪音的主要来源）。

## 6. 动效

- 只对用户操作做反馈：展开/收起 160ms、抽屉滑入 200ms、弹窗淡入 150ms，缓动 `cubic-bezier(.2,.7,.2,1)`。
- **唯一的自发动效**：线路带上的流量脉冲（每条线路上一个小光点按流量速率移动）。`prefers-reduced-motion: reduce` 时完全关闭。
- 禁止：卡片悬停上浮、按钮点击波纹、数字滚动动画、骨架屏闪烁超过 1 种样式。
- 数据刷新时不闪屏：保留旧数据，只在卡片右上角显示小的刷新转圈。

## 7. 图标

- 统一使用 **lucide-vue-next**，线宽 1.75，尺寸 16（表格/按钮内）/ 18（导航）/ 20（空状态以外的强调）。
- 平台 logo 用旧版 `admin/console/logos/*` 文件（复制到 `admin/ui/public/logos/`），模型厂商图标沿用旧版 `model-icons.js` 的映射逻辑。
- 不再使用 Font Awesome 与 Tailwind（新包里不引入）。

## 8. 语气与文案

- 简体中文，短句，动词开头：「添加账号」「刷新额度」「复制地址」。
- 同一动作全流程同名：按钮「禁用」→ 确认框标题「禁用 3 个账号？」→ Toast「已禁用 3 个账号」。
- 错误信息说清楚发生了什么和怎么办：「额度刷新失败：上游返回 401，令牌可能已过期。请重新登录该账号。」不用「出错了，请稍后再试」。
- 空状态给出下一步：「还没有账号。添加账号 / 导入账号」。
- 不用感叹号、不用表情、不用「亲」「哦」。
- 页面副标题只在确有必要时出现，一句话说清这一页干什么；长篇说明折叠进「说明」气泡（`?` 图标）里。
