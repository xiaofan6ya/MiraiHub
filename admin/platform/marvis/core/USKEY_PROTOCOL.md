# marvis uskey：从二进制逆出来的协议说明

本文只讲**协议**与**实现**，不含任何真实设备标识。

## 1. 一条 uskey 长什么样

```
504 字符 base64（自定义表）  =>  376 字节
+------------+------------------------------+
| header 24B | AES-128-CBC(352B)            |
+------------+------------------------------+
   |              |
   |              +-- 解密后 336B = 第二层密文
   +-- 030057040111 || dev18(18B)
```

**关键认知：解出来的 224 字节不是明文，是第二层密文。** 这一层之前骗过很多人。

## 2. 四层变换（自外向内）

### 2.1 外层：自定义 base64

```python
ALPHA = "CDABEFIJHGKLOPMNQRSTWXUVYZabecdfighlmjpqknouyzvrstwx0312546978+/"
```

用标准表去解，会得到一堆「看起来像乱码但其实是错位」的字节 —— 所有后续分析都会跑偏。

### 2.2 AES-128-CBC

```
key = iv = b3641ea93bf54cf4338bcd6c20121641
```

### 2.3 XOR 掩

```
P336 = TEA(...) ^ (C_CONST ^ dev18[2:18])
C_CONST = b3641e533bf54534358bcd6520111645
```

密钥材料 `dev18[2:18]` 来自**明文 header**，所以服务端不需要额外下发密钥。

### 2.4 TEA 双反馈

```
S_i = M_i ^ C_{i-1}
C_i = TEA(S_i) ^ S_{i-1}
S_-1 = C_-1 = 0
```

16 轮，delta `0x9e3779b9`，32 位字**大端**。

## 3. 明文结构

```
stream(336B) = rand8(8) || X1(1) || TLV(320) || 00 x 7
```

TLV 逐段（偏移相对 TLV 起点）：

| 偏移 | 编码 | 内容 |
|---|---|---|
| 0:2 | BE16 | len(TLV) - 2 |
| 2:6 | - | 常量 |
| 6:24 | len + 16B | busid |
| 24:36 | len + 10B | SDK 版本串 |
| 36:45 | len + 7B | appid |
| 45:65 | len + 18B | **设备串 #1** |
| 65:83 | len + 16B | **`md5(bus_info)`** |
| 83:87 | - | 常量 |
| 87:95 | BE64 | epoch 毫秒 |
| 95:112 | len + 15B | 锚点秒（BCD）+ 随机 10B |
| 112:122 | len + 8B | 随机 |
| 122:131 | len + 7B | 版本串 |
| 131:150 | 双层 len + 15B | 进程名 |
| 150:170 | len + 18B | **设备串 #2**（必须与 #1 相同） |
| 170:183 | 双层 len + 9B | 产品名 |
| 183:189 | - | 常量 |
| 189:302 | len + 113B | 周计数 JSON |
| 302:320 | len + 16B | `md5("")` |

**只有 `md5(bus_info)` 和两处设备串需要按请求变化。** 其余是身份常量，跟着 SDK 版本走。

## 4. `bus_info` 七字段

```
marvisAgentTag={agentTag}
&marvisConversationID={cid}
&marvisResponseID={rid}
&marvisScene={scene}
&model={model}            <- 必须是请求体里的原文
&nonce={nonce}
&originOpenID={openid}
```

顺序、分隔符、大小写**都不能变**。改一个字符，`md5` 就对不上，整条 uskey 被拒。

## 5. 实现要点

- AES S-box 用 GF(2^8) 求逆 + 仿射**现算**，不手抄
- TEA 双反馈同时实现加/解密（解密用于回归验证）
- `mint_uskey(qimei36, bus_info, dev18=None)`：`dev18` 默认 `os.urandom(18)`
- `OFF_*` 偏移常量**不要手调**，它们是对着 3 组真实样本校准的

## 6. 边界

本模块**只管签名**。

设备串（`qimei36`，36 个 hex 字符）由**调用方**提供。本模块只把它写进 TLV 两处，
不生成、不派生。它必须与本模块外部构造的 header 里那个值完全一致。

相关环境变量：

| 变量 | 作用 |
|---|---|
| `MARVIS_QIMEI36` | 设备串（36 hex）。**必填**，没有默认值 |
| `MARVIS_USKEY_MIN_BYTES` | 长度闸门，默认 376 |
| `MARVIS_USKEY_FORCE_SIDECAR` | `1` = 强制走旧侧车（对照实验用） |
